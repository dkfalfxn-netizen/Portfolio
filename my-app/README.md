# my-app (Next.js)

포트폴리오 UI·API가 있는 앱입니다.

## 빠른 시작

1. 상위 폴더 **`Portfolio/README.md`** 를 먼저 읽으세요 (환경 변수·배포·다른 PC 설정).
2. 환경 변수: `.env.example` → `.env.local` 복사 후 값 입력.
3. 의존성: `npm install`
4. 개발: `npm run dev` → [http://localhost:3000](http://localhost:3000)

배포는 저장소 루트 또는 여기서 `npm run deploy` (빌드 후 Git 푸시 → Vercel).
